# ORC notice

Rules content used by this project comes from Pathfinder Remaster material
released under the **ORC License** (Open RPG Creative License).

## Status: incomplete, deliberately

**This file is a placeholder and must be completed before any build that ships
content.** It currently describes the obligation rather than discharging it.

No content is distributed with this repository today — the importer downloads
and converts rules data at setup time into a git-ignored folder — so nothing is
being shipped under the ORC yet. That changes the first time a release bundles
converted data.

## What has to be here before content ships

The ORC License requires that the following accompany the distributed content,
reproduced accurately from the license text and the publishers' own notices:

- [ ] The full ORC License text
- [ ] The **Reserved Material** notice for each source, naming what is excluded
- [ ] Attribution for each **Licensed Material** source used, in the form its
      publisher specifies — Player Core, Player Core 2, GM Core, Monster Core
- [ ] Our own attribution line as a licensee

These must be copied from the authoritative published sources. Do not
paraphrase them and do not reconstruct them from memory.
